External services & data

This module is bring-your-own-key. When you route a capability to a provider, Odoo sends the related prompts, embeddings, audio, or image requests to that provider’s API using credentials you configure under Settings → AI.

  • Odoo AI (IAP) — may consume Odoo AI credits when selected
  • Anthropic / OpenAI / Google — traffic goes to those hosts (or your chosen compatible gateway)
  • API keys remain in your database; no third-party activation key is required

Current limitations

  • Google speech-to-text is batch only; live browser STT needs OpenAI or IAP.
  • Google auth uses AI Studio API keys (Vertex service accounts not yet).
  • Requires Odoo Enterprise AI modules (ai_agentic and related apps).
  • Configuration is limited to the Settings / system administrator group.
